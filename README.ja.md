### こんにちは、Aung です 👋

Swift と SwiftUI でネイティブアプリを作る iOS エンジニアです。アプリを支えるバックエンドやツールも自分で作ります。
ESP32 や Arduino を使った IoT 開発もしています。

[English](README.md) · **日本語**
